## [2026-07-24] 阶段 P1：公共基础 + 数据层（完成）

- **做了什么**
  - `common-core`：`R<T>` 统一响应体、`ResultCode` 错误码枚举、`BizException` 业务异常、`BaseEntity` 审计基类、`DataSourceConstants`（pg/mysql 命名常量）；补 `jackson-annotations` 依赖。
  - `common-log`：`TraceIdFilter`（MDC traceId，网关入口生成/透传，Servlet 环境）+ `LogAutoConfig` 注册为最高优先级过滤器；`logback-spring.xml` 统一格式（`%X{traceId}` 串日志）；补 `javax.servlet-api`（provided）。
  - `common-web`：`GlobalExceptionHandler`（BizException/参数校验/兜底 500 → `R`）+ `ResponseAdvice`（领域对象自动包成 `R`）。
  - `ms-user`：pom 加 MyBatis-Plus + dynamic-datasource + PG/MySQL 双驱动；`MybatisPlusConfig`（分页 + 自动填充时间 + `@MapperScan`）；`User`（PG）/ `UserTag`（MySQL，`@DS("mysql")`）实体与 Mapper；`UserService`/`UserTagService`；`UserController`（5 个端点，响应经 `ResponseAdvice` 包装）；启动类 `@ComponentScan("lan.chaos.microservice")` 以纳入 common 层配置；`application.yml` 配逻辑删除 + Jackson 日期串化。
  - DDL：`sql/demo_ms_pg_ddl.sql`（PG `t_user`）、`sql/demo_ms_mysql_ddl.sql`（MySQL `t_user_tag`，`user_id` 用 `BIGINT UNSIGNED` 演示跨方言差异）。
- **踩的坑**
  1. `common-log` 编译报 `javax.servlet` 找不到：`spring-boot-starter`（核心）不带 servlet API，需显式加 `javax.servlet-api`（provided）。
  2. `ResponseBodyAdvice` 泛型签名错：接口要求 `Class<? extends HttpMessageConverter<?>>`，写成裸 `Class` 导致 name clash 编译失败。
  3. `MybatisPlusConfig` 漏 `@MapperScan` import，而启动类又带 `@MapperScan` → 重复扫描会 Bean 重复注册，已统一只留 config 上的。
  4. `@WebMvcTest` 仍会经 `@SpringBootApplication` 的 `@MapperScan` 注册出 Mapper Bean，切片环境无 DataSource 会缺 `sqlSessionFactory` 初始化失败；最终把 `UserMapper`/`UserTagMapper` 也 `@MockBean` 掉绕开（也验证了「Web 切片测试不该碰数据层」）。
  5. `application.yml` 误把 `spring:` 写成两个顶层键会覆盖前面的 Nacos/MyBatis 配置，已合并回同一 `spring` 块。
- **验证结果**：`mvn -o install` 11 个模块全部 **BUILD SUCCESS**；测试 `RTest`×3、`UserControllerTest`×2（切片）、`SqlSliceTest`×1（**H2 离线模拟双库，断言 @DS 路由隔离**）全绿。
- **给你的衔接点**：请在本机 PG 库 `demo_ms_pg` 执行 `sql/demo_ms_pg_ddl.sql`、MySQL 库 `demo_ms_mysql` 执行 `sql/demo_ms_mysql_ddl.sql` 建表。启动 `ms-user` 后可用 `curl` 验证：`POST /users`、`GET /users/{id}`（走 PG）、`POST /users/{id}/tags`、`GET /users/{id}/tags`（走 MySQL）。`application-common.yml` 中 Redis 暂未接入业务，P2/P4 才会用到。
- **下一步**：进入 **P2 熔断限流（Sentinel，优先）**：网关 + Feign 接入 Sentinel 流控/熔断/降级，需把 Sentinel Dashboard 写进 `docker-compose.yml` 并请你启动。
