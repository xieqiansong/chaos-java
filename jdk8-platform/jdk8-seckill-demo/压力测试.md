### 1. 先创建商品

通过 Admin API 创建秒杀商品：

```shell
curl -X POST http://localhost:8081/api/admin/product `
  -H "Content-Type: application/json" `
  -d '{
    "productName": "压测商品",
    "totalStock": 100,
    "bucketCount": 10,
    "price": 99.00,
    "startTime": "2026-07-07T10:00:00",
    "endTime": "2026-07-07T23:59:59"
  }'
```
