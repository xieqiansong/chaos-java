项目名称：chaos 个人开发容器

chaos 是一个个人开发项目容器，用于容纳多个相互独立的代码集合。每个子项目都是独立的 git 仓库，
互不干扰，便于按技术方向分门别类地管理与演进。

技术栈构成：
chaos 容器内包含多个技术方向的子项目，涵盖 Java 后端、Android 客户端、浏览器扩展、
C 语言练习、IntelliJ IDEA 插件、Python 脚本、Spark 大数据处理、前端 UI 组件库等方向。

平台划分原则：
Java 相关代码按 JDK 版本划分为不同平台模块，例如 jdk8-platform 面向仍在维护的老项目，
使用 Spring Boot 2.7.18；jdk11-platform 面向过渡期项目；jdk17-platform 面向新项目，
使用 Spring Boot 3.5.14；更高版本还有 jdk21-tech 与 jdk25-platform 用于前沿技术验证。

编码与文档约定：
容器内的公开项目严禁写入任何敏感信息，包括密码、密钥、Token、API Key、内网地址与个人信息。
日志与路径在发布前需要脱敏处理。文档与注释统一使用中文。

AI 协作约定：
AI 在容器内不主动执行 git 提交与推送操作。归档状态的项目视为只读，AI 不得修改其任何文件，
如需改动必须先由人工解除归档标记。
